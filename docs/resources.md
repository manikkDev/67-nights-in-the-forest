# Resources

Every resource type, where it comes from, and what it's for.

| Resource    | Source                        | Used for                        |
|-------------|-------------------------------|----------------------------------|
| Wood        | Chopping trees (axe)          | Campfire fuel, basic structures  |
| Stone       | Mining rocks                  | Defenses, mid-tier structures    |
| Scrap       | Grinding junk in the Shredder | Tier-2 recipes, upgrades         |
| Berries     | Berry bushes                  | Food (+5)                        |
| Mushrooms   | Forest floor                  | Food (+6)                        |
| Raw Meat    | Deer/owl kills                | Cook at campfire → +15 food      |
| Cooked Meat | Campfire cooking              | Best food (+15)                  |
| CultistGem  | Cultist raids                 | High-tier recipes                |
| Keys        | Cave guards                   | Unlock rescue cages              |

## Inventory notes

- Resources stack; tools and junk items take one slot each.
- Resources and inventory persist across runs — only Base/Rescue/Stats/Campfire profile keys reset.
