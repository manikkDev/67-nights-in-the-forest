# Security Policy

## Supported Versions

This is an in-development game project; only the latest state of the
`main` branch receives fixes.

| Version / Branch | Supported |
| ---------------- | --------- |
| `main`           | Yes       |
| tagged releases  | No        |

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Instead, report privately via GitHub's
[private vulnerability reporting](https://github.com/manikkDev/67-nights-in-the-forest/security/advisories/new)
or by contacting the repository owner directly.

Include:

- A description of the vulnerability and its impact
- Steps to reproduce or a proof of concept
- The affected file(s) or service(s), if known

You can expect an acknowledgement within a few days. Once a fix is
available, a public advisory may be published crediting the reporter
(unless you prefer to remain anonymous).
